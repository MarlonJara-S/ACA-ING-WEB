# Athletix · Prototipo

Prototipo navegable de **Athletix**, una plataforma web de recomendaciones saludables para deportistas de alto rendimiento.

Actividad de Construcción Aplicada (ACA) · Curso de Ingeniería Web.

## Pantallas

1. **Inicio**: bienvenida, categorías, recomendaciones destacadas y resumen de hábitos del día.
2. **Biblioteca saludable**: buscador y filtros por categoría (Nutrición, Hidratación, Recuperación).
3. **Detalle de recomendación**: momento ideal, pasos recomendados, consejo, favoritos y recomendaciones relacionadas.
4. **Favoritos y hábitos**: registro simulado de hidratación y descanso, y lista de favoritos.

## Tecnología

HTML, CSS y JavaScript sin dependencias, con un estilo inspirado en shadcn/ui. Se publica con GitHub Pages.

> Los registros de hábitos y favoritos son una simulación: viven en memoria y no se guardan al recargar.
